# AI-Powered Multimodal Personal Health Intelligence System

This is an offline AI system that analyzes food images, health vitals,
activity patterns, and symptoms to generate personalized health insights.

## Features
- Food calorie estimation using CNN
- Health vitals & activity analysis
- Symptom analysis using NLP
- Explainable AI (SHAP)
- No external APIs

## Tech Stack
Python, TensorFlow, Scikit-learn, OpenCV, FastAPI, Streamlit
